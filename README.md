## Yet another Backpack mod for Fabric, NeoForge and Forge, to get more Inventory space.
___

Resource Backpacks is built for all mainly used Mod-Loader to bring the same experience to each of them.<br>
All Backpacks can be equipped in the Chest Slot and then be opened via Keybind, default ``B``.

Press ```Shift``` to get a compact preview of what's inside your Backpack, this is now a built-in solution so 
[ShulkerBoxTooltip](https://modrinth.com/mod/shulkerboxtooltip) is no longer needed to be installed.

<img src="https://raw.githubusercontent.com/Stein-N/resources/main/images/resource_backpacks/resource_backpacks_tooltip_compact.png" width="300">

### Configuration
The Backpacks, except the End Backpack, Inventory size are configurable within the ``config/resource_backpacks.toml`` config file.
Each of them has a fixed minimum and maximum range for Rows and Columns to have a base balancing.
By default, Backpacks have to be placed like Shulker Boxes to be opened, but within the config u can enable the ability to open them via right-click.
